# TrueTerms — Project Rules

This app helps a newly arrived worker check whether their signed employment contract matches
their original job offer, explain any differences in their own language, and route them to the
correct authority (MOHRE or ADGM).

## Hard rules, never violate these:

1. The rule card text and the routing table text are HARD-CODED CONSTANTS. They are never
   generated by a model call, never paraphrased by a model, never altered.
2. Any model call that explains differences to the user may use ONLY the comparison data and the
   rule card text it is given. It must never invent a law, a deadline, a fine amount, or a phone
   number that was not already supplied to it.
3. The explanation must say "this is different from your offer," never "this is illegal" or any
   stronger legal claim.
4. No chat window, no sidebar, no login screen anywhere in this app. Three screens only: Home,
   Upload, Results.
5. A small deliberate palette is allowed: one primary colour, one warm colour for 'Different', one calm colour for 'Same', plus neutrals. No emojis, no purple or indigo defaults, no sparkle icons, no glassmorphism, no neon glows.
6. Mobile-first, 18px+ text, 44px+ tap targets.
7. The OpenAI API key is read only from a server-side environment variable (OPENAI_API_KEY). It
   must never appear in client-side code, never be sent to the browser, never be committed to any
   file in this repo.
8. The footer "Information only, not legal advice. For help call MOHRE 80084." appears on every
   screen.
9. A "Use sample documents" path must always work using hard-coded demo data, with zero API calls,
   as a guaranteed fallback if the live API is slow or unavailable during the demo.
